# Ice Town — Privacy Policy

Privacy policy page of the puzzle game **Ice Town** («Музли Шаҳарча»), published with GitHub Pages:
https://kurban1978.github.io/icetown-privacy/

Languages: Uzbek (Cyrillic), Russian, English (`#uz`, `#ru`, `#en`).

The source text lives in the game repository (`dizayn/maxfiylik/privacy-policy.md`). To rebuild the page:

```
pip install markdown
python build.py ../IceTown/dizayn/maxfiylik/privacy-policy.md
```
